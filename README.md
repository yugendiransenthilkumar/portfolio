# Yugendiran Senthilkumar — Portfolio

Personal portfolio of a Java Full Stack Developer. Built with React, Vite and Tailwind CSS.

Features: replayable Java terminal hero, project cards with live status and "How it works" notes, category filter, a recruiter fit check that matches a job description against my skills, and a contact form.

## Run locally
```bash
npm install
npm run dev
```

All text lives in `src/data.js`.
